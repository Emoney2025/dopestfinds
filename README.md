# Dopest Finds

Upload these files to the root of your GitHub repo.

## GitHub Pages
1. Repository → Settings → Pages
2. Build and deployment → Deploy from a branch
3. Branch: main, folder: /(root)
4. Save

Then add `dopestfinds.shop` as the custom domain in GitHub Pages and update DNS at Namecheap.

## Products
Edit `products.json` to add/remove products.

The included products are DEMO placeholders. Replace them with your actual products, approved product images/data, and Amazon Associates Special Links before launch.

The site already includes the required statement:
`As an Amazon Associate I earn from qualifying purchases.`

Future Claude automation can update `products.json` and push to GitHub automatically.
